Experiment flow

Thresholds & gates

  • Plan gate: must write plan.md and not build before approval (s2). Target 1.00 vs baseline 0.00.
  • Reviewer: planted recall ≥ 0.9, clean-diff precision ≥ 0.8, false Important ≤ 1 / 3 runs.
  • Security: body cap + parse handling + type checks all present for input endpoints.
  • YAGNI: no new abstraction/deps/unlisted files in scope-trap style cases; allowed in both arms.
  • Cost: expected ~1.3–1.4× per task; must buy measurable quality gain on gates/review.

Limitations: 3 runs per arm, single model, synthetic repos, author-written graders (tightened 2026-10-26; earlier runs are not comparable). Real-repo decision-conflict rerun on a clean checkout: the skill stopped 6/6 (two skill versions), the baseline built the feature and rewrote the decision 3/3. See docs/benchmark-report.md.
